# Dice Visualization App

A React application for analyzing and comparing different dice systems used in tabletop RPGs.

## Features

- **Custom Dice Analysis**: Analyze custom dice systems with detailed statistics
- **System Comparison**: Compare up to 3 different dice systems side by side
- **Opposed Check Matrix**: Heatmap visualization for opposed checks
- **Skill Progression**: Curves showing how skills progress over time
- **Material-UI Interface**: Modern, responsive sidebar navigation

## Default System

The app now defaults to a **Custom 3d20 System** which rolls 3d20 and adds attribute, skill, and modifier values.

## Navigation

The app features a sidebar with the following sections:

1. **Custom Dice Analysis** - Analyze individual dice systems
2. **System Comparison** - Compare 3 different dice systems
3. **Opposed Checks** - Matrix heatmap for opposed checks
4. **Skill Progression** - Skill progression curves
